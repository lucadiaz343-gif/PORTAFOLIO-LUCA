# Portfolio Lucas Díaz®

Aplicación web construida con React, Vite, TypeScript y CSS personalizado.

## Requisitos

- Node.js >= 22.12.0
- npm 11.19.1

## Scripts

| Script              | Descripción                                      |
| ------------------- | ------------------------------------------------ |
| `npm run dev`       | Inicia el servidor de desarrollo con HMR.        |
| `npm run build`     | Verifica tipos y genera el build de producción.  |
| `npm run preview`   | Sirve localmente el build de producción.         |
| `npm run typecheck` | Verifica tipos sin generar archivos.             |
